# ABSTRACT

In an increasingly fast-paced world, traditional time-based reminder systems frequently fail because they lack spatial context; many daily tasks are actionable only when a person is at a specific geographic location. This project introduces **GeoReminder**, an intelligent, context-aware web application designed to eliminate spatial forgetfulness. By leveraging the HTML5 Geolocation API, the system continuously monitors user coordinates and utilizes the Haversine formula to trigger highly accurate, real-time alerts when a user breaches a predefined geofence boundary around a target destination. 

To significantly reduce cognitive load and improve user experience, GeoReminder integrates Natural Language Processing (NLP) through the Google Gemini API. This allows the system to achieve "zero-touch" categorization, instantly analyzing the semantic intent of a user's task to automatically assign relevant visual categories and emojis. Furthermore, the application features dynamic waypoint routing powered by the TomTom Maps API, transforming the tool from a passive list into an active navigational assistant. The entire architecture is underpinned by a robust, serverless backend using Firebase Authentication and Cloud Firestore, ensuring secure, multi-device data synchronization and strict user privacy. Ultimately, GeoReminder successfully demonstrates the integration of modern web technologies, artificial intelligence, and geospatial data to provide a seamless, proactive task management solution.
